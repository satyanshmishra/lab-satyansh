Sort the Changes

In a physical change only shape, size or state changes — no new substance forms. In a chemical change one or more new substances form. Some processes involve both!

Safety & society

If someone’s clothes catch fire, wrap them in a blanket — it cuts off the air supply. Never use a synthetic blanket: it can melt and stick to the skin.

Key ideas

Physical change: shape, size or state changes; no new substance.
Chemical change: new substance(s) form through a chemical reaction.
Lime water turning milky is a test for carbon dioxide.
Combustion needs fuel, oxygen and heat up to the ignition temperature.
A burning candle shows both physical and chemical changes.
Some changes can be reversed; some can’t. Some are desirable; some aren’t.
Weathering and erosion slowly turn rocks into soil and sediments.
